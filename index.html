NOTEBOOK EDITOR — plzsayyes3/mynotebook
v1開く →
パス指定エディタ
既存のファイルパスを指定して開き、編集して保存する、通常のテキストエディタ形式。Markdownプレビュー付き。
v2開く →
タイプライター
カーソルが常に画面中央に固定され、文字は横へ流れていく。画面端で折り返して上段へ積み上がり、Enterで行が持ち上がる、思考をそのまま書き流すための画面。
v2v開く →
縦書きタイプライター
v2の禅モードを縦書きにした派生版。入力位置を画面中央に固定し、文字は上から下へ送り、列が埋まると左へ進む。原稿用紙のように文字を一字ずつ送りながら、日本語を書き流すための画面。
v3開く →
タイプライター + AI漢字変換
v2の書き心地に加えて、ひらがな中心の文章をAI(Gemini)で漢字混じり表記に変換するボタンを追加。誤字脱字も一緒に整える。
v4開く →
自転車モード（音声入力）
走行中の操作を最小化した音声メモ専用画面。キーボードより上だけで画面が完結し、話した内容が末尾に自動で積み上がる。屋外での視認性を優先したライトモードが既定。
v5開く →
縦書きストリーム
改行も列送りもない一本の縦書きストリーム。現在の入力位置を画面中央付近に保ち、新しい文字に合わせて過去の文字が上へ流れていく。思考を止めずに書き続けるための画面。
各バージョンの接続設定(GitHub Token / Gemini API Key)は
この端末のブラウザに共通で保存されます
